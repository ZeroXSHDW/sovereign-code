Questions

Is it really local — does anything leave my Mac?

Yes. Ollama and the LiteLLM gateway bind to 127.0.0.1 only, and the console never calls a cloud API. The only network use is downloading models from Ollama's registry — and that's optional; pre-downloaded models run fully offline.

Do I have to pay to use it?

No. The source is MIT-licensed and buildable free from GitHub. The €5 license is for the ready-to-run package, the pre-built dashboard launcher, lifetime updates, and setup help.

What Mac do I need?

An Apple Silicon Mac (M1 or newer) with macOS 14+, Python 3.11+, and Ollama. It's tuned for a 24 GB M-series machine but scales down to smaller unified memory.

Which models are included?

You bring the models through Ollama. The console already supports 13+ verified models — Qwen, DeepSeek-R1, Gemma, Llama, Mistral, and more — and can download and run any Ollama tag with a single command.

Does it work with ChatGPT, Codex, and Claude Code?

Yes. It wires those clients to your local models through a loopback gateway and auto-resolves the best installed model for each. Qwen Code and OpenCode are verified to edit files locally; Codex and Claude Code work as local chat clients.
