# Code of Conduct

Keep it respectful, constructive, and honest. This project values clear
communication and verifiable claims over hype.

- Be kind and assume good faith.
- Focus on the code and the problem, not the person.
- Do not use this project to evade security controls, spam, or misrepresent
  capabilities.

Unacceptable behaviour may be reported to the maintainer and may result in
removal from the project.
