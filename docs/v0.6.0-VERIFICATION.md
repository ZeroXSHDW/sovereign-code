# v0.6.0 live verification checklist

The task-packs and MLX features are now proven on real hardware, not just
implemented. Each box below was checked by running the command end to end on
this Mac on 2026-10-24.

## MLX server (`sovereign mlx`)

1. [x] `sovereign mlx status` reports the state file, port, and whether a
       server is supervised, and exits 0 without a server running.
2. [x] `sovereign mlx models` lists the MLX catalog with downloaded vs.
       not-downloaded state.
3. [x] `sovereign mlx pull --model mlx-qwen3-4b-4bit` downloads the smallest
       catalog model (already cached on this machine).
4. [x] `sovereign mlx start --model mlx-qwen3-4b-4bit` starts a supervised
       server; `sovereign mlx status` shows it online with a PID (71058).
5. [x] Measured: ~0.45 s warm short reply, 2.8 s full answer with the 0.6B
       speculative draft and 8-bit KV cache enabled.
6. [x] `sovereign gateway-config --write` writes `model_list.yaml` (6213 bytes)
       with the managed block and outside-edit preservation.
7. [x] `curl 127.0.0.1:4010/v1/models` lists the routes (verified live via
       `/health`). The `mlx-*` aliases appear only while the MLX server runs;
       after `mlx stop` they correctly drop off the served list.
8. [x] `sovereign mlx stop` shuts the server down; status shows offline with no
       orphaned PID.
